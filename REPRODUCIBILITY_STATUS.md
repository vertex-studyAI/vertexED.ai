## Reproduction promotion rule

A project advances only when the missing class of evidence is produced. Internal package verification cannot be relabeled independent reproduction; independent reproduction cannot be relabeled peer review; a preprint cannot be relabeled publication; production source tests cannot be relabeled real-user validation.
