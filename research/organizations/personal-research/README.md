## Canonical source policy

The personal archive is a mirror, not a competing source of truth. Canonical source repositories and frozen experiment ledgers control scientific claims. Any future paper gets:

1. source manuscript;
2. compiled PDF;
3. evidence/reproducibility package;
4. claim boundary;
5. submission receipt only after a real submission.
