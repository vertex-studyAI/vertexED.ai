## Branch and task deduplication rule

Historical `agent/*`, `percy/*`, `status/*`, `research/*`, `repro-wave/*`, draft PRs and task branches are provenance, not parallel canonical projects.

A branch/task becomes current work only if it:

1. maps to one canonical project identity;
2. has a precise deliverable and evidence requirement;
3. is not semantically duplicated by a current task;
4. preserves frozen adverse evidence;
5. closes, falsifies or unblocks a current gate;
6. is intentionally merged/reconciled into the canonical source.

Do not delete historical evidence solely to make the graph look smaller.
