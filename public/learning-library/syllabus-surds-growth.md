## GCSE both tiers: exact values and multiples of pi

An exact answer retains all mathematical information, whereas a rounded decimal is an approximation. For example 2/3 is exact but 0.667 is not. For a circle of radius 3 cm, circumference 2πr=6π cm is exact if the radius is exact; 18.85 cm is rounded. Leave π as a symbol when exact form is requested, rather than replacing it by 3.14. Fractions involving π can simplify by cancelling common nonzero factors, so (12π)/(3π)=4.

Exact arithmetic can be carried through several steps. Add fractions with a common denominator and simplify the final ratio rather than rounding each term. The written exact form does not remove uncertainty from measured input: if a radius is rounded, 6π represents the calculation at the stated nominal radius, not an infinitely precise physical circumference. Distinguish exact algebra from precision of measurements.

## Higher / Extended: simplify and combine surds

A surd is an irrational root retained in exact form. For nonnegative a and b, √(ab)=√a√b; extract square factors: √72=√(36×2)=6√2. Combine like surds as like algebraic terms: 3√5+2√5=5√5. Unlike surds cannot usually combine by adding radicands: √2+√3 is not √5. Simplify first because √8+√18 becomes 2√2+3√2=5√2.

Multiply surds using the root product rule, and expand brackets normally. (√3+2)(√3−2)=3−4=−1. An expression can be rational even when its factors contain surds. The rule √(a+b)=√a+√b is false: √(9+16)=5, not 7. Checking one numerical case exposes that mistake, but an identity needs a general justification.

## Higher / Extended: rationalise a denominator

To rationalise 5/√3, multiply numerator and denominator by √3, which is a factor of 1 overall. The result is 5√3/3. For a binomial denominator use its conjugate: multiply 1/(2+√3) by (2−√3)/(2−√3). The denominator becomes 4−3=1, giving 2−√3. The conjugate changes the sign between the terms, not the signs of both terms.

Check that every original and introduced denominator is nonzero. For 3/(√5−1), multiplying by √5+1 yields 3(√5+1)/(5−1)=3(√5+1)/4. Do not multiply only the denominator: preserving value requires the same nonzero factor above and below. Rationalisation is an exact rearrangement, not a rounding procedure.

## IGCSE Extended: discrete exponential change

A constant percentage change applies to the current amount each period. With initial amount P and multiplier a, the value after n equal periods is P×a^n. Growth at r% uses a=1+r/100; decay uses a=1−r/100. For depreciation by 12% annually, the multiplier is 0.88, not −0.12. Population and depreciation models here use discrete time; no knowledge of e is required by this Number point.

A constant decrease of 40 units each year is linear, whereas a decrease of 8% each year is exponential. To determine the first whole period at which a threshold is crossed, test successive integer n or use a table, checking the preceding value too. Interpret rounding in context: a model may give fractional people, but a reported population estimate is rounded at the end. Fixed-rate models assume no changes in rate or external additions; state those limitations rather than treating a projection as certain.

## Worked example 1

[Higher / Extended] Simplify √50+3√8 and rationalise 4/(√6+2).

1. √50=5√2 and 3√8=6√2, giving 11√2.

2. Multiply the fraction by (√6−2)/(√6−2); the denominator is 6−4=2, giving 2(√6−2).

Answer: 11√2; 2√6−4.

## Worked example 2

[IGCSE Extended] A machine valued at £2000 loses 15% of its current value annually. Find its value after three years.

1. The retained fraction each year is 0.85.

2. Compute 2000×0.85³=1228.25; subtracting 15% of the original three times would be a different model.

Answer: £1228.25.

## Misconceptions

- √a+√b always equals √(a+b).
  Correction: The product rule does not extend to sums. √9+√16=7 while √25=5.

- Equal percentage losses remove equal amounts.
  Correction: The base changes each period, so the absolute losses change too.

## Flashcards

Extract √16 to obtain 4√3.

### What is the conjugate of 3+√2?

## Practice 6 — extension · 2 marks

[GCSE Higher; IGCSE Extended] Rationalise 2/(3−√7).

## Practice 7 — extension · 2 marks

[IGCSE Extended] An idealised population of 1600 grows by 2.5% each year for four years. Calculate the model value and round to the nearest whole individual.

Answer: 1600×1.025⁴=1766.100625, giving 1766.

1. Use a growth multiplier of 1.025 each year.

2. Raise it to the fourth power before final rounding.

Marking points (one practice mark each):

- Write the correct exponential model.

## Practice 8 — extension · 2 marks

[IGCSE Extended] A device initially worth £1000 loses 20% of current value annually. Find the first whole year when its value is below £500, checking the preceding year.

Answer: Year 4: £409.60; year 3 is £512, still above £500.

1. Use V=1000×0.8^n.

2. Evaluate successive years: 800, 640, 512, 409.6.

Marking points (one practice mark each):

- Use exponential rather than constant-amount decay.

- Check years 3 and 4 and identify the first crossing.

## Practice 9 — extension · 2 marks

[IGCSE Extended] Model A removes 50 items each month; model B removes 10% of the current stock each month. Starting from 500, compare stocks after two months and name one limitation of model B.

Answer: A gives 400; B gives 405. Model B assumes the same percentage loss with no additions or other changes.

1. For A subtract 2×50.

2. For B multiply 500×0.9²; the second loss is 45 rather than 50.

Marking points (one practice mark each):

- Compute both stocks and distinguish the models.

- State a relevant fixed-rate or closed-stock assumption.

## Revision guide

Exact-number manipulation preserves value; rationalisation uses a factor of one. Exponential models instead describe repeated proportional change over time, with explicitly limited assumptions.
