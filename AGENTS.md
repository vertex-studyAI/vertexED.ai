# VertexED interface work

Before changing UI, read `brand/DESIGN.md`, `brand/COPY.md`, `brand/MOTION.md` and `brand/REFERENCES.md`. They define the persistent product identity. Preserve blue and white, the existing logo, study terminology and the revision trace. Do not replace the identity with a reference site's style.

Use existing controls before adding dependencies. Run copy lint and report legacy findings without hiding them. For visual changes, capture and inspect 1440px, 1024px and 390px, exercise keyboard controls and reduced motion, and perform a correction pass. Never claim a preview deployment updates the production domain.

The canonical runtime boundary is documented in `VERTEXED_REPO_ISOLATION.md`. Unrelated portfolio research is not product evidence. Preserve unrelated uncommitted work.
