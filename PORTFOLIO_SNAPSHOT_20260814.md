## State law

- **A — PUBLISH:** the strongest next output is a defensible paper/report/research release. It does not mean publication has occurred.
- **B — PRODUCTIZE:** the current canonical project should be qualified/released as a usable system. A future scientific successor is a separate version/project.
- **C — CONTINUE EXPERIMENTATION:** a still-live falsifiable question has a meaningful, frozen next gate.
- **D — NEGATIVE RESULT:** preserve a fairly tested failed/mixed scientific hypothesis without in-place rescue.
- **E — ARCHIVE:** no significant active compute this cycle.
- **F — EXTERNALLY BLOCKED:** outside source/deployment/user/hardware evidence is required before the current project can legitimately advance.

Claim-specific GREEN remains separate. A project may be GREEN for a reproducible negative result while its portfolio state is D, or GREEN for implementation while its portfolio state is B/F.
