# EXPERIMENT REGISTRY

The human-readable frozen experiment ledger remains [`EXPERIMENT_LEDGER.md`](./EXPERIMENT_LEDGER.md). The machine-readable registry for Percy is [`EXPERIMENT_REGISTRY.json`](./EXPERIMENT_REGISTRY.json).

This file intentionally does not duplicate experiment outcomes. Update the ledger and JSON registry together when—and only when—a new frozen experiment is registered or a retained reproduction adds evidence without changing the scientific outcome.
