## Selection

### T2424-0025 — robust memory readouts / NGMT precursor
- Hypothesis: under the existing synthetic attention-addressed memory fixture, robust aggregation should degrade less than a weighted arithmetic mean as Cauchy contamination increases.
- Task: fixed latent-anchor retrieval fixture already implemented in the repository.
- Baselines: weighted mean; robust alternatives are weighted median, 10% weighted trimmed mean, and weighted Huber location.
- Primary metric: mean absolute retrieval error (MAE); retain per-condition dispersion from the existing implementation.
- Seed policy: execute the existing 50-seed ablation exactly as committed. No seed filtering.
- Important falsifier/limitation: the 0% contamination control may also favor robust readouts; this prevents a uniquely non-Gaussian-memory interpretation.

### T2424-0027 — latent-language diagnostic mechanics
- Hypothesis: on the frozen synthetic representation with explicitly injected language coordinates, language-centroid subtraction should reduce language-label predictability while preserving concept predictability, whereas global centering should not.
- Task: the repository's fixed 72-record synthetic representation fixture.
- Baselines/controls: raw representation and global-centering negative control.
- Metrics: concept nearest-centroid accuracy, language nearest-centroid accuracy, normalized excess language-leakage reduction.
- Seed policy: deterministic fixture; no seed sweep is scientifically meaningful for this exact generator. The fresh rerun must reproduce retained metrics and pass the independent verifier.
- Limitation: this is not evidence about a real multilingual encoder or linguistic relativity.

### T2424-1768 — self-verifying MoE mechanics
- Hypothesis: on the frozen synthetic scalar fixture, explicit caller-supplied output contracts should reject the predeclared contract-violating expert and improve mixture MAE, while leaving the matched clean control unchanged.
- Task: 81 deterministic scalar samples on the existing fixture.
- Baseline: unverified equal-router-score mixture.
- Proposed mechanism: contract-filtered mixture with fail-closed accepted-expert quorum.
- Metrics: corrupted-condition MAE, clean-control MAE delta, rejection count, quorum failures.
- Seed policy: deterministic fixture; no stochastic training is present.
- Limitation: this does not validate verifier correctness, learned gating, formal verification, safety, or real Scientific-ML benefit.

### T2424-0035 — grokking detector mechanics

- Task: deterministic synthetic learning curves already bundled with the project.
- Baseline/control: matched near-synchronous control.
- Metrics: detector verdict and threshold/delay diagnostics emitted by the existing experiment.
- Seed policy: deterministic fixture.
- Limitation: no claim about grokking in a trained neural network or a causal mechanism.

## Execution policy

Fresh runs must use the repository implementations exactly as present at the frozen base revision except for this orchestration workflow and documentation. The workflow records commit, runner OS/architecture, Node version, UTC time, run ID, raw stdout, test output, and SHA-256 checksums. Existing scientific thresholds are not changed after observing results.

If an execution bug is found, the failed command/log is retained first. Any fix must be a separate commit, explicitly classified as either execution plumbing or protocol-changing, and the old and new outputs must remain distinguishable.

## Statistics policy

Where the existing experiment has multiple seeds, report the full configured sample count plus mean and sample standard deviation when exposed by the implementation. Do not claim statistical significance from these mechanics screens. Deterministic fixtures are reported as deterministic reproductions, not as `n=1` inferential studies.

## Promotion boundary

A fresh green rerun can establish exact-head execution reproducibility of the bounded fixtures. It does not establish external validity, novelty, a full NGMT architecture, real multilingual behavior, real-model grokking, or scientific-MoE superiority.
