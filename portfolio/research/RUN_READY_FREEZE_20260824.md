# Research Run-Ready Freeze — 24 August 2026

## Objective

By the morning handoff, every research line must be classified by repository truth and, where scientifically allowed, reduced to a one-command pre-outcome execution state. This is a preparation gate, not a claim-generation gate.

A project is **RUN_READY** only when its model/method, data path, baselines, experiment configuration, metrics, output schema, tables/figures pipeline, provenance capture, smoke path, and failure criteria are explicit and executable without improvising after outcomes are visible.

## Non-negotiable integrity boundary

- Preserve all frozen negative, mixed, inconclusive, and falsified results.
- Do not use IRIS confirmatory seeds `1000–1029`.
- Do not rescue NGMT v0.1, Eigen-JEPA current version, NeuroCAD typed-parser mechanism, or T2424-1863 in place.
- Do not run T2424-0050 learned training while `training_authorized=false`.
- Do not convert registry identity, source presence, CI, or a draft into scientific completion.
- Unknown source or identity remains **UNKNOWN**.
- Major scientific outcome runs remain disabled until the canonical authorization boundary changes explicitly.

## Universal morning gate

Each active line should have, as applicable:

1. canonical identity and source path;
2. frozen research question and novelty hypothesis;
3. explicit falsification/failure criteria;
4. deterministic environment/configuration lock;
5. dataset manifest or deterministic loader, checksums, and frozen split policy;
6. main method implementation or exact source-recovery blocker;
7. at least one trivial/control baseline and the strongest reasonable matched baseline(s);
8. predeclared metrics with units and aggregation definitions;
9. primary experiment, ablation, robustness/OOD/failure tests where justified;
10. seed/budget policy frozen before scientific outcomes;
11. smoke test that exercises the real data/model/evaluation path on a bounded fixture;
12. immutable run manifest containing commit, config, dataset fingerprints, seed, environment and hardware identity;
13. machine-readable raw result schema;
14. table/figure generation from saved artifacts only;
15. claim gate mapping every quantitative statement to raw evidence;
16. one canonical `run_smoke` path and one canonical full-run/LabOS manifest path;
17. explicit status: `RUN_READY`, `BLOCKED_PROVENANCE`, `BLOCKED_SOURCE`, `FROZEN_RESULT`, `ARCHIVED`, or `UNKNOWN`.

## Definition of success for this freeze

The freeze succeeds when tomorrow's operator does **not** need to invent research decisions while a job is running. The operator should only need to choose an already-authorized manifest, allocate compute, execute it, and collect immutable evidence. Positive, null, mixed, or negative scientific outcomes are all acceptable; unverifiable or post-hoc outcomes are not.
