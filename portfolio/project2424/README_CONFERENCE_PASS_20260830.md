# Conference Readiness Pass

This branch intentionally separates three things that are easy to conflate:

1. **Structural readiness** — files/surfaces exist.
2. **Scientific readiness** — defensible experiment and evidence exist.
3. **Release readiness** — paper, claims, metadata, rendering and venue gates are closed.

No project is promoted merely because documentation exists. The authoritative next step is to audit canonical evidence for each priority lane and then populate the machine-readable readiness table without estimates.
