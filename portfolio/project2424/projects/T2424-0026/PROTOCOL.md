# T2424-0026 — Frozen Minimum Protocol

## PROJECT
`T2424-0026` — Counterfactual Defect Worlds

## CLAIM
A localized defect in the implemented deterministic radius-one cellular automaton remains inside its predeclared causal cone.

## PRIMARY METRIC
Count of causal-cone violations.

## BASELINE
An otherwise identical run with no intervention.

## SEEDS / INITIAL STATE
Deterministic single-center seed generated by `deterministicSeedState(81)`.

## DATA
Synthetic binary cellular-automaton states generated by the implementation; no external dataset.

## SUCCESS THRESHOLD
Exactly `0` causal-cone violations in the frozen Rule-110 run.

## FAILURE THRESHOLD
Any differing cell outside the causal cone, or any non-zero divergence before the intervention.

## NEGATIVE CONTROL
Baseline and counterfactual trajectories must be identical before intervention time `10`.

## ABLATION / CONTROL
The regression suite also exercises Rule 0 and Rule 30 to verify deterministic update and locality mechanics beyond the primary Rule-110 run.

## EXPECTED COST
CPU-only deterministic execution; bounded to 81 cells and 40 update steps for the primary run.

## RUN
```bash
node portfolio/project2424/projects/T2424-0026/experiment/run.mjs
node --test tests/counterfactualDefectWorlds.test.mjs
```

This protocol is frozen for the minimum experiment. Any later stochastic, learned-model, or physical-simulator extension requires a new protocol rather than retroactively changing this gate.
