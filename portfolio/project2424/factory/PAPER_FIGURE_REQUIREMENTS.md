# Minimum Evidence Figures / Tables

For an empirical Project 2424 preprint, the default minimum evidence package is:

- Table 1: primary matched comparison with uncertainty/statistics where applicable;
- Table 2: ablation or mechanism-isolation comparison;
- Figure 1: method/system or protocol schematic;
- Figure 2: headline result generated from raw artifacts;
- Figure 3 or equivalent table: failure/error/robustness analysis;
- supplementary machine-readable run manifest linking every plotted/table value to an artifact.

A project can deviate when the scientific question does not fit this structure, but it must still show enough evidence to support the manuscript claims.
