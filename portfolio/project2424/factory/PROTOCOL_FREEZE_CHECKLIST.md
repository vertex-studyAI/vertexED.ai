# Protocol Freeze Checklist

Before confirmatory execution:

- [ ] question and hypothesis fixed;
- [ ] falsifier fixed;
- [ ] dataset/environment and split fixed;
- [ ] preprocessing fixed;
- [ ] dangerous baselines fixed;
- [ ] primary metric fixed;
- [ ] secondary metrics labeled;
- [ ] seeds/determinism fixed;
- [ ] statistical analysis fixed;
- [ ] success/failure thresholds fixed;
- [ ] compute budget fixed;
- [ ] stop rule fixed;
- [ ] locked holdout/reserved seeds identified;
- [ ] protocol hash recorded.

Any later change creates a new version.
