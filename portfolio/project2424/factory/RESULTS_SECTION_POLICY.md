# Results Section Policy

Results must be written from frozen evidence, not from the desired narrative.

Order by the pre-specified primary question:

1. primary endpoint and matched baseline;
2. uncertainty/statistical analysis;
3. ablations/mechanism tests;
4. robustness/sensitivity;
5. failure/error analysis;
6. negative/mixed/inconclusive findings.

Every numeric value must be traceable to a run/artifact identifier. If a number cannot be traced, it does not enter the paper.
