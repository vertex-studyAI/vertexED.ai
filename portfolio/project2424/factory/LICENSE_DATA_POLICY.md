# Code / Data / Model Licensing Policy

Before preprint release:

- identify licenses for datasets, models, external code and copied benchmark assets;
- verify redistribution and derivative-work permissions;
- do not attach a permissive license to third-party assets that do not permit it;
- state what can and cannot be redistributed;
- provide acquisition/reproduction instructions when raw data cannot be shared;
- record model/data versions and checksums where possible.

A paper can be preprinted when some data cannot be redistributed, but the availability statement must be accurate and the evidence must remain reproducible within legal/ethical constraints.
