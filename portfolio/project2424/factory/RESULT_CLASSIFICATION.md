# Result Classification Vocabulary

Use one of these evidence verdicts where applicable:

- POSITIVE — frozen hypothesis supported within scope.
- NEGATIVE — frozen hypothesis/gate not supported.
- MIXED — important effects differ by condition/metric or key qualifiers prevent a single positive/negative summary.
- INCONCLUSIVE — evidence is insufficient to resolve the hypothesis.
- MECHANISM_NOT_ISOLATED — effect may exist but the proposed causal mechanism is not uniquely supported.
- SYNTHETIC_ONLY — result is valid only on the controlled synthetic setting.
- HISTORICAL — preserved prior evidence not equivalent to a fresh held-out result.
- REPRODUCTION_FAILED — independent rerun did not reproduce the headline within frozen tolerance.

Combinations are allowed when needed, but the manuscript must explain them.
