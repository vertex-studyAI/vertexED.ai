# First-100 Closure Rule

Before expensive expansion across the unresolved registry, every currently named First-100 child should be driven to one honest terminal research state:

- `RESULT_FROZEN` (positive, negative, mixed, or inconclusive),
- `MERGED_DUPLICATE`, or
- `TERMINATED` with a preserved reason.

`IDENTIFIED`, green CI, a runnable toy, or a manuscript shell do not count as scientific closure.

The closure order is evidence/value weighted rather than numerical ID order: complete existing result-bearing projects first, then cheap falsification for unrun projects, then heavier confirmatory work only where justified.
