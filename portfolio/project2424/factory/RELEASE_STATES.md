# Release States

- RESERVED — ID exists, identity unresolved.
- IDENTIFIED — canonical name/question family resolved.
- SPECIFIED — novelty, hypothesis, falsifier, protocol and baselines frozen.
- IMPLEMENTED — canonical code/tests run.
- PILOTED — cheap falsification executed.
- EXPERIMENTED — frozen main experiment executed.
- RESULT_FROZEN — result/artifacts/verdict immutable.
- REPRODUCED — independent rerun agrees within frozen tolerance.
- PAPER_DRAFTED — full manuscript exists but release gate remains.
- PREPRINT_READY — all scientific/manuscript/release gates pass.
- PREPRINTED — public preprint release exists.
- MERGED_DUPLICATE — child preserved as evidence but contribution belongs to another family/paper.
- TERMINATED — project ended with preserved reason.
