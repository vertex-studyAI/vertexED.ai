# Paper Writer Instructions

Write from the evidence package outward.

- Read `RESEARCH_SPEC`, frozen `PROTOCOL`, raw/derived evidence, verdict, claim ledger, and reproduction report first.
- Draft Methods/Experimental Setup/Results before finalizing the abstract/conclusion.
- Cite only verified literature.
- Do not infer unmeasured mechanism/generalization.
- Preserve stronger simple baselines and negative findings.
- Mark unresolved metadata/authorship rather than inventing it.
- A beautiful manuscript with unverified evidence remains blocked.
