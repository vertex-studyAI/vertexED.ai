# Manuscript Directory Contract

Each standalone-paper candidate should eventually contain:

- `paper.tex`
- `references.bib`
- `figures/`
- `tables/`
- `supplement.tex` when needed
- `claim_ledger.md`
- `paper_metadata.json`
- `build.sh` or equivalent deterministic build command
- `paper.sha256` after final build

Family experiments that are not standalone papers should instead link to the family manuscript and identify their section/table/figure contribution.
