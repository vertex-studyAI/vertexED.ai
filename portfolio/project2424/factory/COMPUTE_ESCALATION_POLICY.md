# Compute Escalation Policy

Project 2424 should kill weak hypotheses cheaply.

- Tier 0: analytic/deterministic checks.
- Tier 1: tiny synthetic mechanism screen.
- Tier 2: small real benchmark or simulator slice.
- Tier 3: multi-seed frozen confirmatory experiment.
- Tier 4: expensive scaling only when it answers a material scientific question that survived earlier gates.

A project may not move to a more expensive tier merely because an earlier tier produced an unfavorable result. Escalation requires a documented scientific reason, not hypothesis rescue.
