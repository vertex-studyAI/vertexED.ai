# Definition of a Real Project 2424 Child

A child is `REAL` only when it has all of:

1. canonical identity and lineage;
2. a precise research question;
3. current novelty/duplicate review;
4. falsifiable hypothesis and falsifier;
5. named dataset/environment;
6. credible baseline(s);
7. frozen primary metric/protocol;
8. executable project-specific implementation or an explicit analytic protocol;
9. an evidence state.

A reserved numeric slot, generated title, boilerplate repository, or paper template alone is not a real completed project.
