# Repository Completeness Policy

A child repository is scientifically complete only when the project-specific implementation (or analytic procedure) exists—not merely the common factory harness.

For IMPLEMENTED state require:

- actual project logic under `src/` or a documented analytic workflow;
- credible baseline implementation(s);
- tests for core invariants;
- a clean entry point;
- environment/dependency lock;
- configuration files;
- reproduction instructions;
- no hidden local-only dependency needed for the headline experiment.
