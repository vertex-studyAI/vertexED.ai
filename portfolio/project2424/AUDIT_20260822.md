## Highest-value evidence gap selected

### `T2424-0016` — recover the original PST Prompt-6 source tree

This is an **evidence recovery task, not a reimplementation task**.

The retained handoff states that `/mnt/data/pst_prompt6_bundle/projects/MODEL-PST/` contained source, tests, configs, dataset/baseline contracts, experiment CLIs, evidence, checkpoints, reports, documentation, manuscript sources, compiled PDF, bibliography and a claim-evidence matrix. The canonical Git repository currently contains the recovery package and recorded results, but not that original isolated implementation tree.

The recovered compact evidence is scientifically informative precisely because it contains negative findings:

- simple raw-expression/logistic controls outperform the neural PST variant on the controlled generator;
- validation-only calibration worsens the recorded compact metrics;
- family-A to family-B fixed transfer is weak despite strong family-B in-domain retraining;
- historical Paul15/Pancreas/Dentate headline metrics remain quarantined because their original raw evidence/data identities are unavailable.

Therefore the correct next step is **not** to write a replacement PST implementation from the manuscript and **not** to start a new external experiment. It is to recover an immutable copy of the original isolated tree/archive, validate its hashes/manifests, migrate it without semantic changes, and replay the already-recorded compact protocol from a canonical commit.
