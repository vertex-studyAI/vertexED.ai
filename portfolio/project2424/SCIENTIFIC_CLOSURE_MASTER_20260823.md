## Green definitions

### GREEN — terminal scientific result
All of:
- canonical identity known;
- frozen protocol identifiable;
- raw result retained;
- claim boundary explicit;
- result interpretation explicit;
- reproducibility state explicit;
- negative/adverse controls preserved;
- no unresolved integrity violation that changes the result.

### GREEN — active successor ready to run
All of:
- old result frozen;
- new versioned question explicit;
- baselines and controls frozen;
- dataset/split identities frozen;
- seeds frozen;
- metrics and success/falsification thresholds frozen;
- code/config/environment identities frozen;
- authorization manifest complete;
- no prohibited data/seed access.

### YELLOW — evidence exists but closure incomplete
Examples: source recovered but identity unresolved; result reproducible but claim ledger incomplete; successor protocol drafted but data/model identities missing.

### RED — unsafe or unsupported
Examples: identity collision, silent retune, forbidden-seed use, outcome access before freeze, unsupported publication/SOTA claim, fabricated or missing evidence.
