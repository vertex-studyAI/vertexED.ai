# VertexED Reference Notes

References expand the design vocabulary. They do not provide layouts to copy.

## Lando Norris official site

Reference: https://landonorris.com

Useful properties:

- The site is paced as a sequence rather than a stack of interchangeable sections.
- Large visual moments are balanced by compressed information and direct labels.
- Content categories become part of the composition instead of sitting inside generic cards.
- The experience uses strong contrast between quiet and expressive areas.
- Identity survives beyond the logo because typography, spacing, imagery, pacing, and interaction all point in the same direction.

VertexED translation:

- Treat Plan, Focus, Practise, Review, and Remember as compositional material.
- Let the study trajectory connect landing sections.
- Use dramatic motion only at narrative transitions.
- Keep the logged-in workspace calmer than the public landing experience.

Do not copy:

- motorsport graphics
- lime identity
- page layouts
- imagery
- typography treatment
- branded helmet or track motifs

## Awwwards interaction studies

Reference category: scroll, transition, unusual navigation, and motion studies on https://awwwards.com

Useful properties:

- Strong sites often preserve spatial continuity during scroll instead of fading unrelated blocks in and out.
- Good motion changes composition, hierarchy, or state.
- Narrative sections can use normal scrolling while still feeling cinematic.
- Shared visual material across sections makes a page feel authored.

VertexED translation:

- Continue the Vertex Field through several landing sections.
- Morph real academic objects rather than introducing decorative animation scenes.
- Avoid scroll hijacking.

## Linear

Useful properties:

- compressed navigation
- clear keyboard-first action hierarchy
- calm information density
- contextual controls rather than permanently visible controls
- selected state is obvious without heavy decoration

VertexED translation:

- The logged-in product should become quieter as the user enters focused work.
- Put current task and next action ahead of decorative chrome.

Do not copy the visual skin or layout.

## Stripe documentation and dashboards

Useful properties:

- precise hierarchy in dense technical information
- strong relationship between prose and structured data
- excellent use of whitespace without creating empty pages
- technical objects have consistent visual grammar

VertexED translation:

- Rubrics, attempts, marks, source context, and study tasks should have stable visual grammar.
- Dense academic information should remain readable without turning every group into a card.

## GitHub

Useful properties:

- durable object identity
- context remains visible through deep workflows
- compact metadata can coexist with clear primary content
- history and state are treated as product material

VertexED translation:

- A study attempt, feedback record, and next task should remain traceable as related objects.
- Context Ribbon should preserve subject, topic, task, and attempt location.

## Scientific and graph interfaces

Reference category: scientific visualization, node-link systems, timelines, provenance tools, and experiment dashboards.

Useful properties:

- relationships can be more informative than isolated metrics
- provenance creates trust
- uncertainty and incomplete state can be represented directly
- spatial context reduces the cost of navigating complex systems

VertexED translation:

- The Vertex Field should represent actual workflow relationships.
- Do not show fake mastery graphs or fake model confidence.
- Evidence and task history can become visual material.

## Motion Primitives and Framer Motion patterns

Useful properties:

- shared layout transitions
- controlled presence transitions
- accessible primitives for state change
- motion can be composed from small reliable behaviors

VertexED translation:

- Borrow implementation primitives for Carry, Focus, Flow, and Resolve behavior.
- Restyle and retime everything to the VertexED motion system.

## shadcn and component registries

Useful properties:

- reliable accessibility foundations
- predictable form and dialog behavior
- useful engineering primitives

VertexED translation:

- Reuse primitives where they reduce implementation risk.
- Remove default visual identity.
- Apply VertexED spacing, radius, borders, typography, colors, density, and motion.

## Reference test

For every borrowed idea record:

1. What interaction or structural property is useful?
2. Why does it fit the VertexED workflow?
3. What must change to make it native?
4. What proprietary or branded element must not be copied?

If a finished component is recognizable as a component-library demo or another site's design, it is not finished.
