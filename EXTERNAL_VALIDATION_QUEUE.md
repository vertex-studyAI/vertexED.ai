## External-validation gate format

Every returned validation record must retain:

- validator identity/role and independence relationship
- date
- exact artifact/revision tested
- exact requested action
- raw feedback or machine output
- success/failure interpretation made **before** any rescue changes where practical
- conflicts of interest or prior project involvement
- follow-up action

No testimonial, casual praise, GitHub star, internal agent review, or self-rerun counts as independent scientific validation.
