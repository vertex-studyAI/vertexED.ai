HOW IT WORKS

Language is never executable geometry.

01

Interpret

Supported commands become bounded intents. Unsupported requests fail closed instead of being guessed.

02

Structure

A versioned CAD document describes parametric primitives, transforms and assembly relationships.

03

Validate

Finite dimensions, ranges, radii, stage counts, references and assembly cycles are checked before rendering.

04

Generate

The browser renders validated geometry and can export CADSpec JSON or generated OpenSCAD source.
