## State law

- A scientific result may be negative while the project state is `A — PUBLISH` if the defensible output is the negative-result paper package; this is the case for LAM-JEPA.
- A failed hypothesis that is not yet publication-ready remains `D — NEGATIVE RESULT`; this is the case for IRIS v0.2, NGMT v0.1, Eigen-JEPA and T2424-1863.
- `F — EXTERNALLY BLOCKED` is used when the next decisive truth requires a host, deployment, source archive, user or validator unavailable to this execution surface; it does not mean the existing engineering is poor.
- New successors are separate versioned projects. They never give the falsified predecessor a second state.
