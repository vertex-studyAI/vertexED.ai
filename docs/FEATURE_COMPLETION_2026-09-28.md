## Changes

- Integrated the additional Learning OS work from the original checkout without changing that checkout: a compact Today screen, persistent mobile navigation, time-budget practice, progressive hints, assisted corrections, automatic mistake history and reflections, searchable knowledge views, a contextual tutor and clearer exam/review states. Ten original complex-number questions bring the bank to 35, with an interactive complex plane. This remains bounded question coverage, not a complete curriculum or validated mastery model.
- Text, Markdown and CSV files now have editable title/text review dialogs and detected Markdown headings before saving. Notebook source text opens in a readable side panel. The integration keeps the PDF review modal and account/notebook cancellation guards, and connects the contextual practice tutor to the shared conversation recovery controls.

- Apex conversations use a private account-backed snapshot, shared by the full tutor, companion panel, notebook chat and Socratic drill. Replies retain their source references. Account-owned history supports second-device resume, full-message search, JSON export and revision-checked clearing.
- Saves distinguish device storage, pending account saves, confirmed acknowledgements and failures. Conflicting devices cannot silently overwrite one another. Corruption and quota failures retain recoverable bytes or an in-memory export. Reloading the account copy preserves a device recovery backup. Existing account export and deletion include the conversation artifact and account-scoped device keys.
- Conversation history is bounded to 24 threads, 200 messages per thread and 240 KiB for the collection. Exceeding a bound rejects the new write; it does not silently trim old messages. Recovery backups and legacy session bytes remain available in account export until account/browser cleanup. Clearing a thread is a revisioned empty update, preventing a stale device from resurrecting its cloud copy.
- The tutor has collapsible history controls, conversation selection, search, clear save/recovery controls, wrapping mobile tabs and a visible search field. The redundant floating Apex launcher is hidden on the full tutor page. Account changes reset search/draft scope; Unicode thread links do not split encoded characters.
- The existing PDF-import work was copied into this isolated candidate without modifying its original worktree. PDFs are limited to 1 MB, 25 pages and 50,000 extracted characters. A bounded server worker extracts selectable text without evaluating document scripts. Learners review page-labelled text before adding it. Cancellation and account/notebook changes reject stale results; malformed, encrypted and image-only documents have explicit failure paths. This is text extraction, not OCR, formula interpretation or an assertion that every PDF layout is understood.
- CI now includes conversation, PDF and editable-source browser journeys. The PDF parser and native dependencies are pinned and explicitly packaged with the server function. Client JavaScript limits were retained.
